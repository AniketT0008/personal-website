# Aniket Thakur — Portfolio

Responsive portfolio focused on robotics, computer vision, embedded systems, and applied AI.

## Project structure

- src/app contains the home, work, team experience, skills, about, and contact pages.
- src/data contains the shared site copy, project catalog, team entries, and skills.
- public/images/projects contains project media used by the pages.
- public/resume contains the résumé PDF linked from the site.

## Run locally

Install dependencies with npm install, then start the development server with npm run dev. The app uses Next.js 14, TypeScript, Tailwind CSS, and Framer Motion.

## Review before publishing

This is the refreshed source for the public personal-website repository. The production Vercel project is not linked to it yet. Deploy a preview first, then review team descriptions and active project status before promoting a production build.
